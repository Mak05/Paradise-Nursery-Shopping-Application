# Paradise Nursery Shopping Application

An interactive React-based e-commerce front-end application built for an online house plant shop called Paradise Nursery. 

## Project Features
- **Landing Page:** Welcomes users with an engaging background image, company description, and a "Get Started" call-to-action button.
- **About Us Section:** Details the company's mission and background.
- **Product Catalog:** Displays multiple categories of houseplants (Air Purifying, Aromatic, Low Maintenance) with at least 6 unique items per category, including thumbnails, names, prices, and descriptions.
- **Interactive Cart Management:** Powered by Redux Toolkit to seamlessly add items, disable buttons after adding, update quantities, calculate individual item totals and overall cart totals, delete items, and display a dynamic cart counter badge in the navigation bar.
- **Navigation Bar:** Accessible across both the product listing and cart views with direct navigation links.

## Technologies Used
- React (Functional Components, Hooks)
- Redux Toolkit & React-Redux
- CSS3 for styling
